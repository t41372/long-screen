# 能力边界：逐项对应原需求

“已验证”指有带真值的自动化测试断言，或在真实 Chrome 中实际跑通并检查过输出。

## 移动与轨迹

| 需求                                 | 状态   | 证据                                                                     |
| ------------------------------------ | ------ | ------------------------------------------------------------------------ |
| 上下左右、斜向、非单调二维移动       | 已验证 | `traversal` `diagonal` `horizontal`：位置误差 0，缺失 0，虚构 0          |
| 停止、回滚、反复查看                 | 已验证 | `revisit` 三次经过同一区域；`vertical` 含暂停与反向                      |
| 轻微手抖、非恒定速度                 | 已验证 | `vertical` `phone` 带抖动路径                                            |
| 高速 fling、内容只出现 1–2 帧        | 已验证 | `fling` `glimpse`：单帧可见内容仍进入结果                                |
| 同一内容只出现一次                   | 已验证 | 所有场景断言“虚构像素 = 0”且覆盖集合与观察视口并集相等                   |
| 薄重叠跳转                           | 部分   | 标记 `THIN_OVERLAP_STEP`；回访证据更强时改正并记录，此前像素可能留下接缝 |
| 极慢滚动（逐帧位移低于一个分析像素） | 已验证 | 长基线（帧 t−k 与 t）证据仍能拆出固定头部；`tests/unit/layers.test.ts`   |

| 需求                                                         | 状态               | 说明                                                                                                                                                                                                                                                                                                   |
| ------------------------------------------------------------ | ------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 无重叠跳转不编造距离                                         | 已验证             | `gap`：跳转观察成为独立片段，返回后回到原画布                                                                                                                                                                                                                                                          |
| 独立片段先无重叠跳转、再回访接回主画布，随后继续被回环闭合   | 已验证             | `tests/unit/layers.test.ts` 的 `geometry:` 用例：先 `FRAGMENT_ATTACHED` 整体接回，再对片段接回前后各自的历史区域都能 `LOOP_CLOSURE`，覆盖接回前后混合坐标系下的位置图修正                                                                                                                              |
| 大面积纯色无法判断运动                                       | 已验证             | `blank`：无纹理帧不画到任何位置，报 `UNOBSERVABLE_FRAME`                                                                                                                                                                                                                                               |
| 高度重复内容存在多个合理解                                   | 已验证（含不可解） | `repeated-list` 单向可解；`repeated-list-reversal` 像素级不可分辨，断言误差只能是行高整数倍并给出歧义警告                                                                                                                                                                                              |

## 页面不是静态图片

| 需求                                                   | 状态   | 证据                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| ------------------------------------------------------ | ------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 固定顶栏 / 底栏 / 状态栏                               | 已验证 | 自动识别为固定层，边界定位到原像素；固定画布断言零冲突、像素一致                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| 闪烁光标、实时计数器、播放中的视频（页面坐标动态内容） | 已验证 | 世界一致性掩码（docs/ARCHITECTURE.md §七）允许保留单一完整时刻；`chrome-everything`/`dynamic` 断言 `contaminatedDynamic` 在测得的比率内，主体轨迹误差 0                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| 悬浮按钮、滚动条、鼠标指针、toast（屏幕坐标覆盖物）    | 部分   | 渲染阶段 ±1 帧比较 + `solve()` 位移展开一致性投票（docs/ARCHITECTURE.md §七）把这类内容标记为瞬态（`provisional`，质量遮罩里单独着色，见 `src/ui/viewer.ts`），后续一致观察会覆盖修复；被拒绝的观察若与已覆盖像素逐位相同，会把那个像素一并降级为瞬态。比较容差取自片源声明的解码噪声（`MediaInfo.noise`：压缩视频 10 级，无损片源 0 级即逐像素精确），本次运行用的值记录在 `MODEL_ASSUMPTIONS` 诊断的 `detail.noise`。`dynamic` 场景（鼠标指针）已达成 **0 残留**；`phone` 与 `chrome-everything` 仍有 1,675 / 1,905 个未修复像素，已作为**已知局限**按实测值 +5% 写进各自的 `maxContaminatedOverlayRecoverable` 棘轮（1,759 / 2,001），其余场景仍是默认 0。**该局限的机制**（逐像素复现，见各场景注释）：某个世界位置在录制只剩一两帧时才从滚动前沿进入视口，第一次落笔时正好被覆盖物盖住，而唯一干净的观察是录制的**边界帧**——±1 帧比较是成对信号，同一次分歧会把那一帧也判为不一致，于是它失去修复资格；投票本可以指出该归咎于哪一帧，但在录制边界上不可能有任何一次比较（该位置在所有位移过 Dmin 的参照帧里都不在屏幕上）。这是录制在哪里结束的属性，不是检测器缺陷；这些像素的多数（1,240 / 1,615）**已经被正确标记为瞬态**，只是没有后续观察可以兑现。另有 `contaminatedOverlayUnobservable`（该世界位置整段录制里从未被干净观察到过——`phone` 滚动条滑块所在整列、`chrome-everything` 悬浮按钮的滚动尾端内容），属场景素材本身的几何属性，按各场景自身的解析上限单独棘轮。逐像素溯源与被否决的修复方向见 issue #2 |
| 页面留白边距不被误判为侧栏                             | 已验证 | 侧边带需自身有可见结构才成立                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| 动态区域语义识别                                       | **否** | 只做视觉变化区域处理，不识别“这是视频播放器”                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| 整页来自同一时刻                                       | **否** | 不保证，冲突区域尽量取单一完整观察并记录来源帧                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |

## 内容类型

文字长文、图片、长条漫画、卡片 feed、重复列表、大面积空白、横向与二维内容都有对应场景。输入只有像素，没有 OCR 或语义模型。

## 运行环境

Desktop Chrome 已实测（真实 Chrome，非 Playwright 自带 Chromium，后者没有 H.264）。Playwright WebKit（JSC + WebKit WebCodecs，UA 声明 Safari）也已实测跑通完整重建，包括较大的 HEVC 录屏（1920×1240、1152 帧、21.4 秒）：内存平稳（WebProcess 基线约 550 MB，跑完峰值 +~450 MB，Wasm 峰值 102–120 MB），能完整解码/重建/导出，也能在隐私浏览（临时会话）里跑完演示、把瓦片经 worker 读回、导出 PNG 与 ZIP、刷新后重新打开项目——但隐私浏览的 IndexedDB 只接受字节、拒绝一切 Blob，Blob 值（瓦片 PNG、帧参照）现在探测后自动降级为字节+MIME 存储；隐私浏览也没有 OPFS，导出改为内存中组装（上限 1 GB）并直接走浏览器下载。**真机 Safari（iPhone、iPad、真实 macOS Safari）全流程仍未验证**：已知的两处 Safari 特有差异是（1）Safari 不支持 `VideoFrame.copyTo({format:'RGBA'})`，不支持时改用逐帧核对过的 planar 路径（`copyTo()` 取原生 YUV 布局，核心按 libyuv 公式转 RGBA，首帧同时跑 canvas 比对通过才对整趟启用，否则退回 canvas 转换）；（2）macOS Safari 有独立于内存总量的后台内存回收阈值（页面不可见时门槛骤降），长时间处理放到后台可能被系统回收并重新加载页面——为此有崩溃记录器（`src/ui/flight.ts`）：页面线程每秒记录阶段/帧/内存/已用时间到 localStorage，页面被回收后下次打开会在诊断里给出 `PREVIOUS_RUN_INTERRUPTED`。这些是从 Playwright WebKit 与用户报告的真机崩溃现象归纳出的证据，不等于真机已验证；细节见 [docs/history/2026-09-rust-migration-log.md](history/2026-09-rust-migration-log.md)。Android 全流程未验证。移动尺寸布局只做了 390×844 无横向溢出检查。

## 其他明确未实现

- 断点续算（可恢复已提交结果，不能从中断帧继续）。
- 跨片段的几何关系推断，除非回访给出可靠匹配（此时会整体接回并记录）。
- 兼容 seek 模式的逐帧覆盖保证：它是用户显式选择的近似路径，可能漏帧。
